# FitStore 💪

Aplicación móvil de comercio electrónico enfocada en la venta de suplementos
deportivos, desarrollada con **Ionic + Angular** como proyecto del cuatrimestre.

## Descripción

FitStore permitirá a los usuarios consultar productos y categorías, ver el
detalle de cada producto, administrar un carrito de compras, realizar un
proceso de compra y consultar sus pedidos.

**Categorías iniciales:** Proteínas, Creatina, Pre-entrenos, Aminoácidos,
Vitaminas, Barras de proteína y Accesorios deportivos.

## Tecnologías

- Ionic 8
- Angular (componentes Standalone)
- TypeScript
- HTML
- SCSS
- Capacitor
- Git y GitHub

## Requisitos previos

- Node.js LTS (versión 22 o superior)
- npm
- Ionic CLI (`npm install -g @ionic/cli`)

## Instalación y ejecución

```bash
git clone [URL_DE_TU_REPOSITORIO]
cd fitstore
npm install
ionic serve
```

La aplicación se abrirá en `http://localhost:8100`.
